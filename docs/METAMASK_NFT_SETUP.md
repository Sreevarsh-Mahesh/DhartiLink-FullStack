# 🦊 MetaMask NFT Setup Guide

## How to Add Your NFT Contract to MetaMask

### Step 1: Add the NFT Contract to MetaMask

1. **Open MetaMask** and make sure you're connected to **Sepolia Testnet**
2. **Go to "NFTs" tab** in MetaMask
3. **Click "Import NFTs"**
4. **Enter the contract details:**

```
Contract Address: 0x31b7f507b43a4da7246a650f3e26e0f2c653d361
Token ID: 0 (or any token ID you own)
```

### Step 2: Verify You Own 7 NFTs

Your wallet address: `0x3d5A311f8cbF658E88e55b21149E2081971A5628`

You should see these NFTs:
- Token ID 0: Chennai IT Corridor - Phase 1
- Token ID 1: Chennai Marina Beach Plot  
- Token ID 2: Chennai Industrial Estate
- Token ID 3: Chennai Residential Complex
- Token ID 4: Chennai Tech Park Land
- Token ID 5: Private Delhi Estate
- Token ID 6: Private Mumbai Villa

### Step 3: If NFTs Don't Appear

1. **Refresh MetaMask** (close and reopen)
2. **Check network** - make sure you're on Sepolia Testnet
3. **Try importing each NFT individually** by Token ID
4. **Clear browser cache** and refresh

### Step 4: Verify on Etherscan

Visit: https://sepolia.etherscan.io/address/0x31b7f507b43a4da7246a650f3e26e0f2c653d361

You should see your wallet address in the "Holders" section.

### Troubleshooting

- **If you see 0 NFTs**: The contract might not be properly added
- **If you see only 1 NFT**: Try refreshing or re-importing
- **If NFTs show but images don't load**: This is normal - the metadata URLs are placeholder
